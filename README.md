# Ramkrishna Vidyapeeth Portal

Create a modern, clean, professional, and fully responsive school website for:

School Name:

RAMKRISHNA VIDYAMANDIR

Tagline:

A Bengali Medium Private Co-Educational School

Tech Stack:

- React

- TypeScript (Strict Mode)

- Vite

- Tailwind CSS

- React Router

- Framer Motion for smooth animations

- Lucide React Icons

Do NOT use:

- Firebase

- Supabase

- Database

- Backend

- Login

- Authentication

- CMS

The website should be completely frontend only with reusable components and clean folder structure.

Design Style:

The website should look like a premium educational institution.

Use:

Primary Color:

#0F4C81 (Royal Blue)

Secondary:

#FFD54F (Golden Yellow)

Accent:

White

Background:

Light Gray (#F8FAFC)

Rounded cards

Soft shadows

Modern typography

Large hero sections

Smooth scrolling

Elegant hover effects

Subtle animations

Glassmorphism where appropriate

Fully responsive for Mobile, Tablet and Desktop.

No inline styles.

Generate production-quality code with a premium UI similar to modern educational institution websites. The code should be clean, modular, maintainable, and ready for deployment.

## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
